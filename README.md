# قطة العتش

أداة لتقسيم مصاريف الرحلات الجماعية وتسويتها بين المشاركين.

## المحتويات

- **[trip_ledger.html](trip_ledger.html)** — التطبيق الرئيسي (صفحة ويب مستقلة، كل شيء فيها يعمل محليًا في المتصفح باستثناء تسجيل الدخول):
  - تسجيل دخول ببريد إلكتروني وكلمة مرور عبر خادم صغير (`server/`)، يعمل بنفس الحساب من أي جهاز.
  - قائمة "الأغراض المطلوبة" على شكل لوحة بطاقات تُسحب بين الأعمدة (بأسلوب Trello) لتحديد من سيحضر كل غرض.
  - حسابات لكل مشارك يسجَّل فيها ما اشتراه، مع دعم تكلفة المعسل لمن يدخّن الشيشة فقط.
  - حساب حصة كل شخص تلقائيًا وتحديد أقل عدد تحويلات لتسوية الحساب بين الجميع.
- **[split_trip_expenses.py](split_trip_expenses.py)** — نسخة أولى بسيطة من نفس الفكرة كسكربت طرفية (command line).
- **[server/](server/)** — خادم صغير (Node.js/Express + PostgreSQL) مسؤول فقط عن تسجيل الدخول/إنشاء الحساب (`/api/signup`, `/api/login`, `/api/me`)، منشور على Render. لا يخزّن أي بيانات عن الرحلات أو المصاريف — تلك تبقى في متصفح كل مستخدم.

## التشغيل

افتحوا `trip_ledger.html` مباشرة في أي متصفح. كل الميزات تعمل محليًا بلا خادم **باستثناء تسجيل الدخول**، الذي يحتاج اتصالًا بخادم `server/` المنشور على Render — تأكدوا أن `API_BASE` أعلى سكربت `trip_ledger.html` يشير إلى رابط الخادم الفعلي.

### تشغيل خادم تسجيل الدخول محليًا (اختياري، للتطوير فقط)

```
cd server
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/dbname JWT_SECRET=devsecret npm start
```
